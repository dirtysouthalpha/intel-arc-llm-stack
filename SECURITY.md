| Version | Supported |
| ------- | --------- |

## Reporting a Vulnerability

Please report security vulnerabilities via GitHub Security Advisories for this repository.

Do not open a public issue for a security vulnerability. Include as much detail as you can, including steps to reproduce, the affected version, and any relevant logs (redact secrets and internal hostnames/IPs first).
